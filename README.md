# ondine-it-media

Hébergement public (GitHub Pages) des médias publiés sur le compte Instagram Ondine.IT.
L'API Instagram exige une URL publique pour chaque image ou vidéo.

Arborescence : `NNN_Sujet/reel/` et `NNN_Sujet/carrousel/` (images en JPEG).
